# Contributing

Contributions are welcome. You can help by reporting issues, suggesting improvements, or submitting a pull request.

## Before submitting

- Keep changes focused and consistent with the existing project.
- Test the dashboard in a modern browser, including the board hover behavior and notation feedback when relevant.
- Do not include credentials, private keys, or unrelated generated files.

## Pull requests

1. Create a feature or fix branch from `dev`.
2. Make and test your changes, then commit them with a clear message.
3. Push your branch and open a pull request targeting `dev`.
4. Explain the change and include the checks you performed.

See [WORKFLOW.md](WORKFLOW.md) for the full branch workflow.
